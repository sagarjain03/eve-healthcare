# Edge Cases — Coverage Matrix

Every row is handled in code and covered by at least one automated test.
All error responses use `{"error": {"code", "message", "details"}}`.
Test paths are relative to `apps/` (except those starting with `tests/`, which are at the repo root); `::name` is the pytest test function.
