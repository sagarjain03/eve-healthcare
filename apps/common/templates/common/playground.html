EVE Diagnostics — API Playground

Testing page (dev only). Every button calls the real API; responses appear in the log. Swagger Admin
This page must be opened from the Django server, not as a file / Live Server. API calls go to the same address the page came from, so here they will fail (e.g. 405). Open http://localhost:8000/playground/ instead (the Docker container or runserver must be running).
